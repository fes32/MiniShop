# MiniShop — локальное приложение интернет-магазина

**MiniShop** — учебный проект на C# и .NET 8, представляющий собой локальное приложение интернет-магазина. Проект разработан для практики объектно-ориентированного программирования, многослойной архитектуры, работы с базами данных и создания интерактивных веб-интерфейсов.

## Возможности

- **Каталог товаров** — просмотр доступных товаров.
- **Поиск и фильтрация** — поиск нужных товаров в каталоге.
- **Корзина** — добавление товаров и изменение их количества.
- **Имитация покупки** — оформление тестовой покупки с уменьшением количества соответствующих товаров в базе данных.
- **Панель администратора** — добавление, редактирование и удаление товаров.
- **Локальная база данных** — хранение информации о товарах в SQLite.
- **Готовая сборка** — запуск приложения в Windows без необходимости открывать проект в Visual Studio.

## Используемые технологии

- C#

## Архитектура проекта

Решение разделено на несколько проектов, каждый из которых отвечает за свою часть приложения:

| Проект | Назначение |
|---|---|
| `MiniShop.Domain` | Доменные модели и основные сущности предметной области |
| `MiniShop.Application` | Прикладная логика и сервисы |
| `MiniShop.Infrastructure` | Доступ к базе данных и реализация репозиториев |
| `MiniShop.Api` | API-контроллеры для работы с данными |
| `MiniShop.Web` | Веб-интерфейс и запуск приложения |

Такое разделение упрощает поддержку и развитие приложения, а также демонстрирует принципы многослойной архитектуры.

## Запуск готового приложения

Для быстрого запуска не требуется устанавливать Visual Studio.

1. Перейдите в раздел **Releases** этого репозитория.
2. Скачайте архив `MiniShop-v1.0.0-win-x64.zip`.
3. Распакуйте архив в папку, доступную для записи.
4. Убедитесь, что файл `minishop.db` находится рядом с `MiniShop.Web.exe`.
5. Запустите `MiniShop.Web.exe`.
6. Дождитесь автоматического открытия браузера.

**Важно:** не удаляйте `minishop.db` и не заменяйте его без необходимости. В этой базе хранятся тестовые товары и их количество. Перед заменой базы рекомендуется сделать резервную копию.

## Запуск из исходного кода

### Требования

- Windows
- Visual Studio 2022
- .NET 8 SDK

### Инструкция

1. Склонируйте репозиторий или скачайте исходный код.
2. Откройте файл `MiniShop.sln` в Visual Studio.
3. Дождитесь восстановления NuGet-пакетов, если Visual Studio предложит это сделать.

Установите MiniShop.Web в качестве запускаемого проекта.

Запустите приложение.

### База данных

Для хранения данных используется SQLite.

В опубликованной версии приложение ожидает файл minishop.db в той же папке, что и исполняемый файл MiniShop.Web.exe.

В исходном коде демонстрационная база находится в папке sample-data/, если она включена в репозиторий.

### Ограничения

Проект предназначен для обучения и демонстрации навыков разработки.

Покупки являются тестовыми: реальные платежи не выполняются.

Приложение не предназначено для использования в качестве полноценной коммерческой платформы без дополнительной разработки и мер безопасности.
